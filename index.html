Getting started

  1. Open RunLens and choose Explore demo workspace to try sample experiments without a server.
  2. For your own runs, choose Connect a server and enter your SSH connection and experiment directory.
  3. Verify the SSH server fingerprint against a trusted source before connecting.
  4. Open a run, then use Charts, Config, and Logs. Pin your key metrics and add a RunLens widget from the Home Screen.

Requires iOS/iPadOS 27.0 or later. Real experiments require an accessible SSH server, a Python environment with wandb installed, and readable local W&B logs. The app interface is English.

Troubleshooting

Cannot connect

Check the host, port, credentials, and network connection. Connect your device to the appropriate VPN for private servers. The server must allow SSH commands, not only SFTP.

No experiments found

Try Wandb auto search, or choose a more specific experiment directory. Confirm the SSH user can read the logs and that your training process has recorded data.

Python environment not found

Turn off automatic Python discovery, enter the Python executable from your training environment, and use Check Python environment. RunLens does not install Python or packages.

Widget values look old

Check the widget’s Read timestamp. iOS controls background refresh timing. Open RunLens and reconnect if your server or VPN was unavailable. Saved credentials are required for background access.

Server identity changed

Confirm the change with your server administrator. Forget the saved server identity only after you have independently verified the new fingerprint.

처음 사용하기

  1. Explore demo workspace에서 서버 없이 샘플 실험을 살펴보세요.
  2. 실제 실험은 Connect a server에서 SSH 연결 정보와 실험 디렉터리를 입력하세요.
  3. 서버 지문을 신뢰할 수 있는 경로로 확인한 뒤 연결하세요.
  4. Charts, Config, Logs에서 데이터를 확인하고, 지표를 Pin한 뒤 홈 화면에 RunLens 위젯을 추가하세요.

iOS/iPadOS 27.0 이상이 필요합니다. 실제 서버에는 Python, wandb 패키지, 읽을 수 있는 로컬 실험 로그가 있어야 합니다. 앱 인터페이스는 영어입니다.

문제가 생겼나요?

  • 연결 실패: 서버 주소, 포트, 인증 정보, 네트워크·VPN을 확인하세요. SSH 명령 실행이 허용되어야 합니다.
  • 실험이 안 보임: Wandb auto search를 사용하거나 로그가 있는 디렉터리를 지정하고 읽기 권한을 확인하세요.
  • Python 탐색 실패: 학습 환경의 Python 실행 파일 경로를 직접 입력하고 Check Python environment를 실행하세요.
  • 위젯 갱신 지연: Read 시각을 확인하세요. 실제 갱신 시점은 iOS가 결정하며, 서버 연결과 저장된 인증 정보가 필요합니다.
  • 서버 지문 변경: 관리자에게 변경 여부를 확인한 뒤 저장된 서버 지문을 지우고 다시 연결하세요.

개인정보처리방침에서 연결 정보와 위젯 데이터의 처리 방식을 확인할 수 있습니다.
