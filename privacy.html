RunLens is an independent W&B experiment viewer developed by Junbum Lee. This policy explains how the iOS app handles data.

Data collection by the developer

RunLens has no developer-operated account or cloud service. The app does not send experiment logs, SSH credentials, usage analytics, advertising identifiers, or tracking data to the developer. No advertising or analytics SDK is included.

Connections you choose

When you connect, the app communicates directly with the SSH server you specify. It uses your username and authentication method to access that server, sends a read-only Python program for execution there, and reads W&B metrics, run configuration, metadata, and recent console output. Folder discovery searches readable folders in that SSH user’s home directory. Your server or network provider may keep its own connection logs.

RunLens does not sync these logs to W&B Cloud or install a persistent server agent. Your training software may separately send information to other services; that activity is outside RunLens.

Information stored on your device

  • Connection profiles include host, port, username, experiment path, Python settings, and a display name.
  • Local preferences include trusted server identities, pinned metrics, chart smoothing, and appearance settings.
  • If you choose to remember credentials, passwords, private keys, and passphrases are stored in the device’s Keychain using device-only protection. The app does not enable iCloud Keychain synchronization for these records.
  • Without remembered credentials, authentication information is held for the current session and cleared on disconnect.

Home Screen widgets

The app and its widget extension share local snapshots of pinned metrics, project/run identifiers, and display metadata through an App Group. Passwords and private keys are not written into widget preferences.

When you connect with remembered credentials, a separate device-only Keychain record allows the widget extension to read your pinned metrics from the verified server. It can be available after the first unlock following a device restart. iOS decides when background refreshes run. Widgets retain the last successful snapshot when a server is unavailable and show its read time.

Your choices

You can disable remembered credentials, turn off widget auto-refresh, disconnect, or remove a saved server in Connection settings. Removing a saved server removes its saved credentials and widget snapshots; project pins may remain as local preferences. These actions do not delete or modify experiment logs on your server.

You can use the demo workspace without connecting to a server. RunLens does not require a RunLens account, so there is no developer-held account to delete.

Support and this website

If you email support, the developer receives the information you choose to include and uses it to respond to your request. Do not send credentials or unredacted private experiment logs. This documentation site uses GitHub Pages and has no analytics scripts or advertising. GitHub handles hosting requests under its privacy statement. Apple’s App Store and optional system diagnostics are governed by Apple’s policies.

Changes and contact

This policy will be updated if RunLens’s data practices change. The effective date appears above. For privacy questions or requests about support correspondence, contact junbum.me@gmail.com.

RunLens는 Junbum Lee가 개발한 독립 W&B 실험 뷰어입니다. 이 방침은 iOS 앱에서 데이터를 처리하는 방식을 설명합니다.

개발자의 데이터 수집

RunLens에는 개발자가 운영하는 계정이나 클라우드 서비스가 없습니다. 앱은 실험 로그, SSH 인증 정보, 사용 분석 정보, 광고 식별자 또는 추적 데이터를 개발자에게 전송하지 않습니다. 광고·분석 SDK를 포함하지 않습니다.

사용자가 지정한 서버와의 연결

앱은 사용자가 지정한 SSH 서버에 직접 연결합니다. 입력한 사용자 이름과 인증 방식으로 인증하고, 서버에서 실행할 읽기 전용 Python 프로그램을 전달해 W&B 지표, 실행 설정, 메타데이터, 최근 콘솔 출력을 읽습니다. 폴더 자동 탐색은 해당 SSH 사용자의 홈 디렉터리에서 읽을 수 있는 폴더를 검색합니다. 서버나 네트워크 제공자는 자체 접속 기록을 보관할 수 있습니다.

RunLens는 로그를 W&B Cloud에 동기화하거나 서버에 상주 에이전트를 설치하지 않습니다. 학습 프로그램이 다른 서비스로 전송하는 데이터는 RunLens의 처리 범위에 포함되지 않습니다.

기기에 저장하는 정보

  • 서버 주소, 포트, 사용자 이름, 실험 경로, Python 설정, 연결 이름을 기기에 저장합니다.
  • 신뢰한 서버 지문, Pin한 지표, Smoothing 값, 화면 모드 등의 설정을 로컬에 저장합니다.
  • 인증 정보 기억을 선택하면 비밀번호·개인키·패스프레이즈를 해당 기기에서만 사용할 수 있는 키체인 보호 방식으로 저장합니다. 이 항목에 대해 iCloud 키체인 동기화를 활성화하지 않습니다.
  • 인증 정보 기억을 끄면 현재 세션에서만 인증 정보를 사용하며 연결 해제 시 지웁니다.

홈 화면 위젯

앱과 위젯 확장은 App Group을 통해 Pin한 지표의 스냅샷, 프로젝트·실험 식별자, 표시 정보를 기기 안에서 공유합니다. 위젯 설정에는 비밀번호나 개인키를 기록하지 않습니다.

인증 정보 기억을 켜고 연결하면 별도의 기기 전용 키체인 항목을 통해 위젯이 검증된 서버의 지표를 읽을 수 있습니다. 이 항목은 기기를 재시작한 뒤 처음 잠금을 해제한 이후 사용할 수 있습니다. 백그라운드 갱신 시점은 iOS가 결정합니다. 서버에 연결할 수 없으면 마지막으로 성공한 스냅샷과 읽은 시각을 유지합니다.

사용자의 선택

인증 정보 기억이나 위젯 자동 갱신을 끄고, 연결을 해제하거나 저장된 서버를 제거할 수 있습니다. 서버를 제거하면 해당 서버의 인증 정보와 위젯 스냅샷을 지웁니다. 프로젝트별 Pin 설정은 로컬 설정으로 남을 수 있습니다. 서버의 실험 로그는 삭제하거나 수정하지 않습니다.

서버에 연결하지 않고 데모 작업 공간을 사용할 수 있습니다. RunLens 계정이 필요하지 않으며 개발자가 보관하는 앱 계정도 없습니다.
